# 🔐 Налаштування Telegram Login

## 📋 Огляд

Система авторизації підтримує **два типи входу**:
1. **👨‍💼 Адмін панель** - вхід по паролю (для адміністраторів)
2. **📱 Telegram Login** - вхід через Telegram (для клієнтів)

---

## 🚀 Налаштування Telegram Login Widget

### Крок 1: Отримати Telegram Bot Username

1. Відкрийте [@BotFather](https://t.me/BotFather) в Telegram
2. Знайдіть свого бота (який ви вже створили)
3. Запам'ятайте username бота (без @)

**Приклад:** Якщо ваш бот `@kyiv_malyn_bot`, то username = `kyiv_malyn_bot`

### Крок 2: Увімкнути Telegram Login для бота

Відправте команду BotFather:
```
/setdomain
```

1. Оберіть свого бота
2. Введіть ваш домен: `malin.kiev.ua`

### Крок 3: Налаштувати змінні середовища

#### Локально:

Створіть файл `frontend/.env`:
```bash
VITE_TELEGRAM_BOT_USERNAME=kyiv_malyn_bot
```

#### На Railway:

1. Перейдіть в Railway Dashboard
2. Відкрийте ваш frontend проект
3. Variables → New Variable
4. Додайте:
   - Name: `VITE_TELEGRAM_BOT_USERNAME`
   - Value: `kyiv_malyn_bot` (ваш bot username)

## 💡 Як це працює

### Для клієнтів:

1. **Перший візит:**
   - Клієнт відкриває сайт
   - Бачить кнопку "🔑 Логін" в меню

2. **Вхід через Telegram:**
   - Натискає "Логін"
   - Обирає "📱 Вхід через Telegram"
   - Клікає на Telegram Login Widget
   - Авторизується в Telegram
   - Може ввести номер телефону вручну

3. **Автозаповнення:**
   - Номер автоматично зберігається
   - При наступному бронюванні поле "Телефон" заповнюється автоматично
   - В навігації відображається: "📱 +380501234567"

4. **Прив'язка до бота:**
   - При першому бронюванні після входу
   - Telegram User ID автоматично прив'язується до бронювання
   - Бот знає цього клієнта і відправляє тільки йому повідомлення про його бронювання

### Для адміністраторів:

1. **Вхід:**
   - Натискає "🔑 Логін"
   - Обирає "👨‍💼 Адмін панель"
   - Вводить пароль
   - Отримує доступ до адмін панелі

2. **Навігація:**
   - Показується кнопка "👨‍💼 Адмін панель"
   - Доступна кнопка "🚪 Вийти"

## 🎯 Особливості системи

### Безпека:
- ✅ Кожен клієнт бачить **ТІЛЬКИ свої бронювання** через `/mybookings` в боті
- ✅ Telegram User ID унікальний і не може бути підроблений
- ✅ Адміни мають окремий доступ до всіх бронювань

### Зручність:
- ✅ Номер телефону зберігається після входу
- ✅ Автоматичне заповнення при бронюванні
- ✅ Немає потрібності вводити номер кожного разу
- ✅ Кнопка "Логін через Telegram" на сторінці бронювання

### Прив'язка:
- ✅ При першому бронюванні після входу через Telegram
- ✅ Автоматично копіюється з попередніх бронювань (якщо номер співпадає)
- ✅ Бот знає користувача і відправляє персональні повідомлення

## 🧪 Тестування

### Локально:

1. Запустіть frontend: `npm run dev`
2. Відкрийте `http://localhost:5173`
3. Натисніть "Логін" → "Вхід через Telegram"
4. Якщо бот не налаштований - побачите помилку (це нормально для локального тесту)

### На production:

1. Переконайтеся що `VITE_TELEGRAM_BOT_USERNAME` налаштовано в Railway
2. Відкрийте https://malin.kiev.ua
3. Натисніть "Логін" → "Вхід через Telegram"
4. Telegram Login Widget має працювати
5. Авторизуйтеся через Telegram
6. Номер має автоматично заповнитися при бронюванні
