### 3. 🔔 Нагадування про поїздки
**Статус:** ✅ Працює автоматично (таймер у процесі бекенду, зовнішній cron не потрібен)

Для кожного бронювання (час поїздки — київський) бот шле до трьох нагадувань, кожне — не більше одного разу:

| Тип | Коли | Текст |
|-----|------|-------|
| **За день до поїздки** | 20:00 напередодні (бронь створена до 20:00) | «Нагадуємо про вашу поїздку завтра» |
| **В день поїздки** | 08:00 (бронь створена до 08:00, до відправлення ≥ 30 хв) | «Сьогодні у вас поїздка!» |
| **Перед поїздкою** | лише якщо бронь не потрапила під два вищі: за 2 год до відправлення, а якщо на момент броні лишалося менше 2 год — за 30 хв; менше 30 хв — не нагадуємо | «Через 2 години / 30 хвилин у вас поїздка!» |

**Як працює:**
1. Таймер раз на хвилину (`BOOKING_REMINDERS_INTERVAL_MIN`, `0` — вимкнено) шукає нагадування, час яких настав.
2. Клієнту з `telegramChatId` — повідомлення в бот, інакше (або при збої) — платний SMS-фолбек.
3. Надіслане записується в `BookingReminder` (унікально `bookingId + kind`): повторів немає — навіть при ручному запуску чи двох контейнерах під час деплою.
4. Нагадування включають маршрут, дату, час, ім’я, водія (для попуток).

Деталі, правила та змінні: **[RAILWAY_CRON_REMINDERS.md](./RAILWAY_CRON_REMINDERS.md)**, код — `backend/src/booking-reminders.ts`.

**Вручну** (admin, заголовок `Authorization: <ADMIN_TOKEN>`; ділять журнал із таймером):
```bash
curl -X POST https://your-backend.railway.app/telegram/send-reminders        -H "Authorization: $ADMIN_TOKEN"  # завтрашні
curl -X POST https://your-backend.railway.app/telegram/send-reminders-today  -H "Authorization: $ADMIN_TOKEN"  # сьогоднішні
```

### 4. 🤖 Інтерактивні команди (ОНОВЛЕНО - БЕЗПЕЧНІ!)
**Статус:** ✅ Працює

Бот відповідає на команди клієнтів:

#### `/start`
Привітання та автоматична перевірка реєстрації.

**Логіка:**
- Перевіряє чи користувач вже зареєстрований (по Telegram User ID)
- Якщо ТАК - показує підтвердження та номер телефону
- Якщо НІ - пропонує зареєструватися і показує кнопку "Поділитися контактом"

#### `/help`
Довідка по всіх доступних командах (адаптована під статус користувача).

#### 📱 **Реєстрація через контакт** (НОВИНКА!)
**Спосіб 1:** Кнопка "Поділитися контактом"
- Telegram автоматично надсилає номер
- Найбільш безпечний спосіб

**Спосіб 2:** Написати номер вручну
- Будь-який формат: +380, 380, 0
- Бот автоматично розпізнає

**Логіка:**
- Нормалізує номер телефону
- Знаходить всі бронювання з цим номером
- Прив'язує **Telegram User ID** до всіх бронювань
- Зберігає Chat ID для нотифікацій

#### `/mybookings` (НОВИНКА - БЕЗПЕЧНА!)
Перегляд **ТІЛЬКИ СВОЇХ** бронювань.

**Логіка:**
- Шукає бронювання по **Telegram User ID** (НЕ по номеру телефону!)
- Показує тільки майбутні бронювання
- До 10 найближчих бронювань
- **Неможливо переглянути чужі бронювання**

#### `/addviber` (тільки для адміна в адмін-чаті)
Додати оголошення з Вайберу без заходу в адмінку — та сама логіка, що при кнопці «➕ Додати оголошення».

**Як працює:**
1. Адмін в чаті боту пише `/addviber`
2. Бот просить надіслати текст оголошення (такий самий, як вставляють в адмінці)
3. Адмін вставляє одне повідомлення з Вайберу або блок з кількох
4. Бот парсить, створює оголошення(ня), надсилає сповіщення адміну та (якщо є телефон) автору в Telegram; збіги водій/пасажир теж обробляються

Очікування на наступне повідомлення — 10 хв.

#### ~~`/subscribe`~~ та ~~`/booking`~~ (ВИДАЛЕНО)
**Старі небезпечні команди видалено!**
- Дозволяли переглядати бронювання за номером телефону
- Порушували конфіденційність
- Замінено на безпечну систему з `/mybookings`

## 🛠️ Технічні деталі

### Архітектура

**Файли:**
- `backend/src/telegram.ts` - Telegram сервіс
- `backend/src/index.ts` - API endpoints
- `TELEGRAM_CLIENT_GUIDE.md` - Інструкція для клієнтів

**База даних:**
- Поле `telegramChatId` в таблиці `Booking` - для відправки повідомлень
- Поле `telegramUserId` в таблиці `Booking` - для ідентифікації користувача (**НОВИНКА!**)
- Зберігає прив'язку користувача до його бронювань

**Режим роботи:**
- `polling: true` - бот постійно слухає команди
- Працює на Railway без додаткових налаштувань

---

### API Endpoints

#### `POST /bookings`
Створення бронювання з автоматичними нотифікаціями:
1. Відправляє повідомлення адміну
2. Перевіряє чи клієнт підписаний
3. Якщо так - відправляє підтвердження клієнту

#### `POST /telegram/send-reminders` (admin)
Відправка нагадувань за день до поїздки (бронювання на завтра).

#### `POST /telegram/send-reminders-today` (admin)
Відправка нагадувань у день поїздки (бронювання на сьогодні).

**Response:**
```json
{
  "success": true,
  "message": "Нагадування відправлено: 5, помилок: 0",
  "total": 5,
  "sent": 5,
  "failed": 0
}
```

#### `GET /telegram/status` (admin)
Перевірка статусу Telegram інтеграції.

**Response:**
```json
{
  "enabled": true,
  "adminChatId": "configured",
  "botToken": "configured"
}
```

### Функції в telegram.ts

#### `sendBookingNotificationToAdmin(booking)`
Відправка повідомлення адміну про нове бронювання.

#### `sendBookingConfirmationToCustomer(chatId, booking)`
Відправка підтвердження клієнту.

#### `sendTripReminder(chatId, booking)`
Відправка нагадування за день до поїздки («завтра у вас поїздка»).

#### `sendTripReminderToday(chatId, booking)`
Відправка нагадування в день поїздки («сьогодні у вас поїздка»).

#### `getChatIdByPhone(phone)`
Отримання Chat ID клієнта по номеру телефону (з перевіркою telegramUserId).

#### `registerUserPhone(chatId, userId, phoneInput)` **НОВИНКА!**
Реєстрація номера телефону користувача та прив'язка до Telegram User ID.

#### `isTelegramEnabled()`
Перевірка чи налаштований Telegram Bot.

#### `setupBotCommands()`
Налаштування обробників команд бота.
