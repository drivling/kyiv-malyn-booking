# Проєкт власника 2025 року — зупинки по порядку й час у дорозі

Власник сайту 2025 року зібрав розклад міських автобусів Коростеня у вигляді сторінок «маршрут + напрямок»
(«Розклад станом на 25.07.2025 року», © Меренков Сергей) і далі проєкт не розвивав. Для
[плану транспорту Коростеня](../../../Docs/korosten-transport-2026-11.md) це головне джерело **порядку зупинок і
часу між ними** — того, чого в даних ради нема.

| Файл | Що це |
|---|---|
| `html/<маршрут><напрямок>.html` | 16 вихідних сторінок: №1–8, напрямок 1 (від вокзалу / першої кінцевої) і 2 (назад). Імена скорочено до коду, зміст не змінено |
| `chains.json` | ті самі сторінки, розібрані `backend/src/korosten-project-parser.ts` |
| `REPORT.md` | звірка з розкладом ради й переліком зупинок ради |
| `../stop-aliases.json` | назва зупинки з проєкту / розкладу ради → зупинка ради `z-0NN`; ручні підказки — `../stop-aliases.hints.json` |

Перегенерувати `chains.json`, `stop-aliases.json` і `REPORT.md` (без мережі):

```bash
cd backend && npm run build && npm run korosten:snapshot -- --project
```

## Що є на кожній сторінці

- **Послідовність зупинок** з накопиченим часом у хвилинах від початкової; «(на вимогу)» у назві.
- **Відправлення від початкової зупинки** окремо для робочих днів і вихідних.
- **Примітки** до окремих рейсів: літера біля хвилин («Н» — по вул. Південна, «С» — початок із «Гастелло»,
  «М» — через Грозине), зірочка, сіре тло (`depot`), підкреслення (`und`).

## Чого тут нема

- Маршруту №2-Б (три ранкові рейси в розкладі ради).
- Координат зупинок.
- Шляху рейсів з примітками: якими зупинками автобус їде по Південній, через Франка, через Грозине, до «Сади»
  й «Дачі УТОС». Ці гілки є на [схемі 2019 року](../scheme-2019/README.md).

## Формат `chains.json`

`directions[]`: `code` («61»), `route`, `direction` (1 / 2), `title`, `from`, `stops[]` (`name`, `onDemand`,
`minute`), `departures.weekdays[]` / `.weekends[]` (`time` HH:MM, `mark` або `null`), `notes[]` (`mark`, `text`),
`asOf`.
