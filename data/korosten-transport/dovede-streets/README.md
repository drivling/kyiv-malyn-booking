# Вулиці Коростеня для «Доведе»

Крок 7а плану навчання (`Docs/dovede-learning-roadmap.md`): адресу в Коростені («на Грушевського 12») сторінка знаходить
у цих даних і веде планувальником у браузері — без запиту до сервера й Google.

- `fetch_osm.py` — знімок OpenStreetMap: місто плитками з офіційного API (`api.openstreetmap.org/api/0.6/map`; Overpass
  з робочого середовища недоступний), обрізане межею міста (Nominatim). Пише `osm/streets.json` (дороги з назвою і
  геометрією) та `osm/addresses.json` (обʼєкти з номером будинку) — у тому ж вигляді, що знімок Малина, а також
  `../dovede-landmarks/osm/places.json` (названі місця для орієнтирів, крок 7б). Потрібна мережа, запускається вручну;
  тимчасову відмову сервера повторює сам.
- `build.py` — спільний із Малином генератор (`data/malyn-transport/dovede-streets/build.py`, функція `build`): пише
  `frontend/src/pages/DovedePage/data/korosten-streets.json`. Мережі не потребує.

```bash
python3 data/korosten-transport/dovede-streets/fetch_osm.py   # оновити знімок (≈ 1 хв)
python3 data/korosten-transport/dovede-streets/build.py       # зібрати файл сторінки
```

Знімок 2026-11-21: 249 вулиць, 795 будинків з вулицею в OSM (`houses`) і 704 привʼязані за геометрією (`near`).
Перевірка привʼязки на будинках із відомою вулицею: 468 правильно з 494 (95 %), як і в Малині; пороги й пояснення — у
README генератора Малина. Одну назву пропущено як повтор id («вулиця Південний Пост» — у знімку є і «Південний Пост
вулиця»).

Id вулиць у файлі — `street.<slug>`; сторінка ставить їм простір `kstreet.` (`korosten/korostenStreets.ts`), бо назви
вулиць у Малині й Коростені збігаються. Серверної копії назв немає: промпт Claude для Коростеня вулиць не містить.
