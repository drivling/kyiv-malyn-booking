# Орієнтири Коростеня для «Доведе»

Крок 7б плану навчання (`Docs/dovede-learning-roadmap.md`): заклад без власної зупинки («до АТБ», «до школи 5», «до
міської ради») сторінка знаходить у цих даних і веде планувальником у браузері — без запиту до сервера й Google.

- `osm/places.json` — знімок OpenStreetMap: названі місця з тегом закладу в межах міста. Пише
  `../dovede-streets/fetch_osm.py` (той самий запуск, що оновлює вулиці й будинки; офіційний API OSM плитками).
- `config.json` — ручні рішення: центр міста, виключення (не місце або надто загальна назва), памʼятки-орієнтири,
  народні назви (`aliases`). Нову назву чи виключення додавати тут, а не в згенерованому файлі.
- `build.py` — спільний із Малином генератор (`data/malyn-transport/dovede-landmarks/build.py`, функція `build`): пише
  `frontend/src/pages/DovedePage/data/korosten-landmarks.json`. Мережі не потребує.

```bash
python3 data/korosten-transport/dovede-streets/fetch_osm.py     # оновити знімок (вулиці, будинки, місця)
python3 data/korosten-transport/dovede-landmarks/build.py       # зібрати файл сторінки
```

Знімок 2026-11-22: 304 названі обʼєкти → 150 орієнтирів (дитсадки, підприємства, школи, АЗС, супермаркети, пошта,
аптеки, установи…). Не ввійшли: місця без відомого роду закладу, меморіали й військова техніка в парку (крім
переліку `memorials`), загальні назви («Аптека», «Продукти», «Кафе»), садові товариства, поштові індекси.
Однойменні місця (АТБ, «Подорожник», UPG…) мають `twins`: сторінка показує ближче до центру й каже, що їх кілька.

Id у файлі — `lm.<slug>`; сторінка ставить їм простір `klm.` (`korosten/korostenStreets.ts`). Серверної копії назв
немає: промпт Claude для Коростеня орієнтирів не містить. Зупинка датасету з такою самою назвою має перевагу — розбір
знаходить її раніше.
