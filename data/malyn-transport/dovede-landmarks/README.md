# Орієнтири Малина для «Доведе»

Місця без власної зупинки, які люди називають замість неї: магазини, аптеки, установи, підприємства, заклади
(«до АТБ», «в пенсійний», «до садка 8»). План — `Docs/dovede-roadmap.md`, фаза 4.

```bash
python3 data/malyn-transport/dovede-landmarks/fetch_osm.py   # новий знімок OSM → osm/places.json (потрібна мережа)
python3 data/malyn-transport/dovede-landmarks/build.py       # з кореня репозиторію, мережі не потребує
```

`fetch_osm.py` одним запитом до Overpass (кілька дзеркал по черзі) бере всі названі заклади в рамці міста. Генератор
читає цей знімок і ручні рішення `config.json`, пише два файли (руками їх не правити). Після нового знімка
перегляньте різницю в списку: у OSM трапляються назви-жарти й закриті заклади — їх додають у `exclude`.

| Файл | Що в ньому |
|------|------------|
| `frontend/src/pages/DovedePage/data/malyn-landmarks.json` | id `lm.<slug>`, рід місця, назва, підпис, як його кличуть (`said`), точка, адреса з OSM, `twins` |
| `backend/src/dovede/landmarks.ts` | id, підпис і `said` — для промпту Claude (без координат) |

Тест `frontend/.../nlu/landmarks.test.ts` звіряє списки id в обох файлах.

## Правила

- Беруться лише названі обʼєкти дозволених родів (`KINDS` у `build.py`). Банкомати, перукарні, кіоски, технічні
  споруди — ні. Меморіальні дошки й знаки — лише ті, що в `memorials` (решта названі прізвищами, як вулиці).
- Заклади з номером отримують звичні назви самі (`numbered()`): «Малинський Ліцей №3» — «ліцей 3», «школа 3»,
  «3 школа»; «ДНЗ №8 Ялинка» — «садок 8», «Ялинка».
- Той самий обʼєкт двічі в OSM (точка й будівля ближче `sameM` метрів) — одне місце.
- Однойменні місця в різних кінцях міста отримують `-2`, `-3`; перше — ближче до центру. Усі вони мають `twins`,
  і відповідь каже людині, яке саме показано.
- `config.json`:
  - `exclude` — чого не брати. Зокрема місця, які вже є в кураторському словнику (лікарня, лісотехнікум, Прожектор,
    паперова фабрика), і крамниці з назвою-іменем чи звичайним словом («Марія», «Гараж», «Експрес») — вони давали б
    хибні відповіді на звичайні речення;
  - `aliases` — як ще кажуть. Слова до 4 літер звіряються точно, тому короткі пишіть у потрібних відмінках
    («суд», «суду»); у назві з кількох слів 4-літерне слово відмінюється саме («нової пошти»);
  - `noShort` — назви, які не можна скорочувати, відкинувши «КП / ТОВ».
- Зупинка чи місце кураторського словника з такою самою назвою має перевагу в розборі: туди їде автобус.

## Чого тут немає

Закладів, яких немає в OpenStreetMap. Додавати — правкою самої карти OSM і новим знімком, або за списком «Чого не
впізнали» в `/admin/dovede`. Координати з Google сюди не потрапляють.
