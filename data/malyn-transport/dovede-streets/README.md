# Вулиці Малина для «Доведе»

`build.py` збирає з OSM-знімка жовтневого аудиту (`../audit-2026-10/osm/streets.json`, `addresses.json`) два файли:

- `frontend/src/pages/DovedePage/data/malyn-streets.json` — 271 вулиця: назва, тип, колишні назви (`old_name`), точка
  на вулиці, довжина і будинки з координатами у двох списках:
  - `houses` — 326 будинків, для яких вулицю вписано в OSM (`addr:street`);
  - `near` — 2634 будинки, де в OSM є лише номер і точка: вулицю визначено за геометрією (найближча вулиця);
- `backend/src/dovede/streets.ts` — лише id і назви, для промпту Claude.

```bash
python3 data/malyn-transport/dovede-streets/build.py   # з кореня репозиторію, мережі не потребує
```

## Привʼязка будинку до вулиці за геометрією

У знімку 6047 обʼєктів з `addr:housenumber`, але `addr:street` вписано лише в 575. Для решти беремо найближчу
вулицю, якщо вона не далі 45 м і друга за близькістю вулиця щонайменше на 30 м далі та у 2,5 раза далі
(`MAX_DIST_M`, `MIN_GAP_M`, `MIN_RATIO` у `build.py`). Кутові будинки й будинки у дворах (2162) лишаються без вулиці;
той самий номер на одній вулиці у двох місцях далі 60 м одне від одного (20 пар) не беремо.

Перевірка на будинках із відомою вулицею (`houseStats.check` у JSON): з 205 привʼязаних 195 привʼязано правильно
(95%), 332 спосіб пропустив. Помилки — багатоквартирні будинки у дворах, адресовані до головної вулиці, що стоять
ближче до провулка; вибірка зміщена в бік саме таких будинків, тож для приватного сектору точність, імовірно, вища,
але виміряти це нічим. Тому `near` у відповіді «Доведе» позначається як «знайшов за розташуванням — може бути трохи
неточно», а не як точна адреса. Навіть помилково привʼязаний будинок стоїть не далі 45 м від названої вулиці.

Координати Google сюди не додаємо й не зберігаємо: умови Google Maps Platform забороняють будувати з них власну базу
(кеш координат — до 30 днів), і в проєкті Google — лише перевіряльник (`CLAUDE.md`, Коростень).

Обидва файли згенеровані — не редагувати вручну. Тест `frontend/.../nlu/streets.test.ts` звіряє списки id.
Id вулиці — трансліт назви (`street.horodyshchanska`, провулок — із суфіксом `-provulok`); після перейменування
вулиці в OSM id зміниться, стара назва лишиться в `old`.

Щоб оновити знімок OSM, потрібен Overpass (`../audit-2026-10/scripts/`); з хмарного середовища Claude Code він
недоступний — оновлювати з машини власника.
