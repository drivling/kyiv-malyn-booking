# GTFS КП «Київпастранс» — свої дані «Доведе»

Архів GTFS міського транспорту Києва (трамваї, тролейбуси, автобуси КП «Київпастранс»), який власник «Доведе»
готував у проєкті Київради й передав 2026-11-23 як свої дані — так само, як дані метро й кільцевої електрички.
На сторінці без згадки джерела й без застережень (правило власника).

- `gtfs_static.zip` — архів як є (feed_version 20261123, чинний до 2027-11-23).
- `REPORT.md` — що увійшло в дані «Доведе» і чого в архіві немає (генерується).
- `backend/src/dovede/kyiv-kpt-data.ts` — компактні дані для сервера (генеруються; на сервері каталогу `data/` немає).

```bash
cd backend && npm run build
npm run kyiv:kpt                       # з архіву в репозиторії
npm run kyiv:kpt -- ~/Downloads/gtfs_static.zip   # новий архів на місце старого
KPT_GTFS_URL=<адреса експорту> npm run kyiv:kpt -- --fetch   # свіжий архів із експорту КПТ
```

Адресу експорту має власник; у репозиторій її не кладемо (сервер проєкту, не публічна сторінка). З хмарного
середовища розробки вона недоступна (мережа не пускає на IP-адреси) — оновлювати з комп'ютера власника. Після
оновлення: тести (`npx vitest run src/dovede/kyiv-kpt.test.ts`), `npm run build`, PR.

## Що в архіві

У рейсі лише 2–8 контрольних точок (кінцеві й кілька проміжних), а не всі зупинки; зупинки окремі для кожного
маршруту, назви скорочені. Лінії маршрутів (`shapes.txt`) проходять через контрольні точки, але 65 % з них — пряма з
2–3 точок, тож дорогою вони не є і в дані не беруться. Маршрутних таксі й приміських автобусів в архіві немає — для
них, як і для пішої частини, лишається Google.
