# Маршрутки Києва — перелік міста

`routes.json` — знімок набору «Розклад руху міського електричного та автомобільного транспорту» на
data.kyivcity.gov.ua (ресурс routes, CKAN datastore): номер маршрутки й опис («кінцеві. Тривалість маршруту N хв.
Частота відправлення A-B хв.»). Дані власника, як GTFS «Київпастрансу»: на сторінці «Доведе» без згадки джерела.

Оновити (з будь-якої машини, адреса публічна):

```bash
cd backend && npm run build && npm run kyiv:kpt -- --fetch-taxi
```

Скрипт перепише `routes.json` і `backend/src/dovede/kyiv-taxi-data.ts`; тест `kyiv-own-lines.test.ts` тримає обидва
рівними генератору. Руками не редагувати.

Лінії маршруток із зупинками (шар routeTaxi ГІС «Майно», `gisserver-stage.kyivcity.gov.ua`) з хмари недосяжні —
коли власник завантажить GeoJSON з України, його покласти поруч і додати до генератора.
