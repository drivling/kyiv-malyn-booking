# Коростень — ручна перевірка перед запуском і після (smoke)

Мастер-план: [`korosten-transport-2026-11.md`](korosten-transport-2026-11.md), фази 11.1–11.2. Автоматично перевіряє
збірка (`seo-smoke` дерева `dist/sites/korosten/`, юніт-тести міста); тут — те, що бачить людина на справжньому домені.
Чекліст — на 15–20 хвилин; знайдене записати в мастер-план («Знахідки по фазах»).

## 0. Перед прапорцем — у перегляді адміна (malin.kiev.ua, увійти в адмінку)

Відкрити `https://malin.kiev.ua/transport?city=Korosten` — жовта смужка «Перегляд транспорту: Коростень».

- [ ] Хаб: «Транспорт Коростеня», 9 ліній, чіпи «Куди їдете?» (вокзал, ринок, центр, лікарні, водосховище), карта на
      Коростені. У підвалі — три джерела: «Розклад: Коростенська міська рада», «Зупинки: data.gov.ua (CC BY)»,
      «Координати зупинок: © учасники OpenStreetMap».
- [ ] Планувальник, будень і субота (дата в чіпі): Пашини → Поліське водосховище (№2 → №1), Шухевича → Вул. Київська
      (№7 → №4), Станція Житомирська → Проліскова (№6 → №3). Рейси №7 «через вул. Франка» (07:35, 08:39) є в будень і
      зникають у суботу.
- [ ] Вихідні №2 (фаза 7): `/transport/route/2` у будень — 16:40\* і 17:25\* від Шухевича; у суботу — 16:40 і 17:10 від
      вокзалу. Пашини → вокзал о 16:00 у суботу — рейс до вокзалу, не до Шухевича.
- [ ] Табло `/transport/stop/st_1001`: блок «Про зупинку» — «у Коростені — вул. Героїв небесної сотні», лінії №1…№8 і
      №2-Б; в суботу нема рейсів «лише по буднях».
- [ ] Схема `/transport/scheme`: 9 ліній, плакат PDF/SVG відкривається, під схемою — джерела (нема блоку «Дані відкриті»).
- [ ] Ніде нема слова «Малин», крім FAQ хаба «Міжміські … Київ / Житомир / Малин — на /mizhgorodski».

## 1. Увімкнення (власник)

1. Адмінка → «Маршрути» → Коростень → «Локальний транспорт» ✓ → зберегти.
2. **Redeploy фронтенда** (Railway → frontend → Redeploy). Статичні сторінки Коростеня пишуться лише збіркою, яка вже
   бачить публічний датасет міста. У лозі збірки мають бути рядки
   `prerender-transport-stops[korosten]: dataset from API`, `prerender-spa: 11/11 pages written` (хаб, схема, 9 маршрутів)
   і `seo-smoke[korosten]: … 0 failing`. Рядок «транспорт міста не опубліковано» = прапорець ще не збережено або API
   не відповідав — збірку повторити.
3. GA4 (раз): Admin → Custom definitions → custom dimension, scope «Event», parameter `transport_city`
   ([`transport-analytics.md`](transport-analytics.md)).

## 2. Після деплою — korosten.kiev.ua

У звичайному вікні (не адмін), телефон і комп'ютер.

- [ ] `https://korosten.kiev.ua/transport` — хаб Коростеня без смужки перегляду; меню «Транспорт Коростеня».
- [ ] Ті самі пункти, що в розділі 0 (планувальник, вихідні №2, табло, схема, джерела в підвалі).
- [ ] `https://malin.kiev.ua/transport` — Малин без змін (data.gov.ua і телефон у підвалі).
