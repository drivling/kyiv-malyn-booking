# Схема міських маршрутів Малина (стиль метро)

Октолінійна схема 8 міських маршрутів (2, 3, 5, 7, 8, 9, 11, 12): кінцеві, центральні та вузлові
зупинки, легенда з «через», кількістю рейсів і часом першого/останнього. Не в масштабі.

- `malyn-transit-scheme.svg` — самодостатній файл (світла тема) для друку, месенджерів, соцмереж.
- `index.html` — та сама схема як сторінка зі світлою/темною темою й примітками.
- `build_scheme.py` — генератор. Геометрія (вузли, коридори, смуги) задана вручну в коді;
  легенда рахується з `/transport/dataset` (кількість рейсів у кожен бік, перший–останній).

Перегенерувати після зміни розкладів або геометрії:

```bash
cd Docs/malyn-transit-scheme
python3 build_scheme.py                       # дані з Railway API
python3 build_scheme.py --dataset dataset.json  # або з локального JSON (GET /transport/dataset)
```

Маршрути з прапорцем `unreliable` (зараз 1, 10, 10-old) на схему не потрапляють — список
`ROUTE_ORDER` у генераторі треба оновити вручну, якщо з'явиться новий маршрут.
