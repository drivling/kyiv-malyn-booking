Бот: [@malin_kiev_ua_bot](https://t.me/malin_kiev_ua_bot) · Сайт: [malin.kiev.ua/mizhgorodski](https://malin.kiev.ua/mizhgorodski)

**Публічна сторінка допомоги (для користувачів):** [malin.kiev.ua/support](https://malin.kiev.ua/support) — хаб тем; гайд бота: [/support/bot](https://malin.kiev.ua/support/bot). Редірект `/help` → `/support`. Старі якорі `#bot` тощо на хабі перенаправляють на відповідну статтю.

Документ нижче — робоча копія для адміна/розробки. Оновлено 05.08.2026.

## 1. Перший запуск

1. Відкрийте бот у Telegram.
2. Натисніть **Start** або напишіть `/start`.
3. **Поділіться номером телефону** (кнопка «Поділитися контактом»). Без номера не працюють бронювання, персональні кнопки в `/allrides` і виплати в акції «Приведи друга».
4. Знизу з’явиться **меню** (Маршрутки, Попутки, Акції, Довідка).

## 3. Попутки (`/allrides`)

- Показує активні оголошення водіїв і пасажирів.
- **Фільтри:** сьогодні, завтра, майбутні, конкретна дата, час доби.
- Якщо у вас є оголошення з **точним співпадінням** маршруту, дати й часу — з’являються кнопки швидкого запиту до другої сторони.
- Для водіїв з Telegram — посилання **«Забронювати»** (`book_viber_ID`).
- Кнопка **«Поділитися попутками в чат»** — вставляє список у **текущий** чат через inline-режим.

Без номера в боті: список видно, але персональні кнопки й бронювання недоступні.

---

## 4. Inline: `@бот` у групі або з другою

Inline-режим дозволяє **не відкривати бот**, а вставити готове повідомлення в будь-який чат.

### Как набрать

1. У полі введення чату напишіть `@malin_kiev_ua_bot` (або `@` і виберіть бот).
2. З’явиться підказка (placeholder) і список **карточок**.
3. Виберіть карточку — Telegram відправить текст у чат.

### Пустий запит (лише `@бот`)

Меню з чотирьох пунктів:

- **Запросити друга** — акція «Приведи друга»
- **Попутки сьогодні**
- **Допомога** — короткий список команд
- **Забронювати** — посилання в бот

### Конкретні запити

| Запит | Результат |
|-------|-----------|
| `ref_share` | Персональне посилання «Приведи друга» (потрібен `/start` у боті) |
| `rides_today` | Оголошення на сьогодні (до 20 карточок) |
| `rides завтра` / `rides київ` | Попутки з евристикою дати/маршруту |
| `help` | Текст допомоги |
| `book` | Посилання на бронювання |
| `share_listing_123` | Поділитися **своїм** оголошенням #123 |

### Кнопки в боті

- **Поділитися з другом** (`/invite`) — `switch_inline_query: ref_share`
- **Поділитися оголошенням** — після `/adddriverride` або в `/mydriverrides`
- **Поділитися попутками** — в `/allrides`

---

## 5. Акція «Приведи друга»

1. `/invite` — умови, персональне посилання, кнопки:
   - **Поділитися з другом** (inline)
   - **Копіювати посилання**
   - Запросити за номером / @username
   - Моя статистика
2. Друг відкриває посилання → `/start` → реєструється номер → додає попутку.
3. Для бонусів пасажира: друг підтверджує поїздку **двома фото** через `/confirmride`.
4. Виплати — після модерації фото в адмінці.

**Не працює:** само-запрошення з двох номерів в одному Telegram-акаунті (блокується).

---

## 6. Підтвердження поїздки фото (`/confirmride`)

1. Виберіть поїздку зі списку.
2. Надішліть **фото 1** — старт (місто відправлення).
3. Надішліть **фото 2** — прибуття (місто призначення).
4. Виконайте крок з постом у Facebook (як просить бот).
5. Адмін модерує фото; після схвалення бонуси йдуть у чергу виплат.

При відхиленні — причина в боті; можна надіслати нові фото через `/confirmride`.

## 7. Бронювання через посилання

- `t.me/malin_kiev_ua_bot?start=book_viber_123` — запит на бронювання у водія з оголошення #123.
- `t.me/malin_kiev_ua_bot?start=book` — відкриває `/book`.
- `t.me/malin_kiev_ua_bot?start=driver` / `passenger` — сценарії з сайту poputky.

## 8. Номер для inline-бронювання (`setup_phone`)

Якщо в inline з’являється підказка про номер:

1. Натисніть **«Відкрити бот і додати номер»** (switch to PM).
2. У боті поділіться контактом.
3. Поверніться в чат — кнопка **«Попутки в цей чат»** або знову `@бот rides_today`.

## 9. Для адміністратора бота

Лише в чаті `TELEGRAM_ADMIN_CHAT_ID`:

| Команда | Дія |
|---------|-----|
| `/referralreport` | Короткий звіт реферальної програми |
| `/addviber` | Додати оголошення з Viber |
| `/addtelegram` | Імпорт з Telegram-групи |
| `/checkclients` | Перевірка збігів пасажир↔водій |

Веб-адмінка: вкладка **Реферали** — виплати, фото, антифрод.

### BotFather (inline)

- `/setinline` — **placeholder** (підказка в полі `@бот`). Рекомендовано змінити з «Запросити друга…» на:
  **`Попутки, акція, бронювання…`**
  (BotFather → `/setinline` → вибрати бот → ввести текст → Enter).
- `/setinlinefeedback` — **Enable, 100%** (для вашого масштабу 10–700 юзерів). Бот уже пишe в лог `inline_chosen …` — див. §9.1.

### 9.1. Inline feedback (після Enable 100%)

Нічого додатково в коді не треба — обробник уже на проді (коміт inline-плану).

1. **Деплой** — backend з `chosen_inline_result` (якщo ще не на сервері).
2. **Перевірка:** у групі `@malin_kiev_ua_bot` → виберіть карточку (напр. «Попутки сьогодні») → відправте в чат.
3. **Логи сервера** (Railway / docker): шукайте рядки:
   `inline_chosen result_id=menu_rides_today from=…`
   або `result_id=ride_123`, `referral_share`, `share_listing_42`.
4. **Що аналізувати вручну** (раз на місяць або після розсилки):
   - `menu_ref` / `referral_share` — шаринг акції
   - `menu_rides_today`, `ride_*` — попутки
   - `share_listing_*` — водії діляться оголошенням
5. **Не використовуйте** для виплат, бронювання, антифроду — Telegram не гарантує 100% доставку (кеш inline).

Таблиця в БД / дашборд — лише якщо зросте трафік; зараз достатньо логів.

## 10. Часті проблеми

| Ситуація | Рішення |
|----------|---------|
| Бот не пише | Розблокуйте бот, `/start` |
| Немає кнопок у `/allrides` | Поділіться номером; потрібне точне співпадіння маршруту/часу |
| Inline пустий | Перевірте, що inline увімкнено в BotFather |
| `ref_share` без посилання | Спочатку `/start` у боті |
| Не виплачують бонус | Фото не схвалені / flagged / бот заблокований |
