## Навіщо (2026-11-17)

Розклади міжміських маршруток лежать у таблиці `Schedule` (адмінка `/admin/schedules`, `PUT /schedules/:id` з
`priceUah`). Ціни Житомир → Малин у вересні 2026 знімали з табло автовокзалу Житомир-1 (через polissya.today), і вони тихо
застаріли: 283–299 → 329–339 грн. Власник 17.11 оновив їх руками й хоче, щоб наступна зміна прийшла сама — в адмін-чат.

Що показали два пошукові звіти (17.11.2026):

- єдине **живе** джерело цін — табло системи «Автовокзал-Сеть» МПП «ВПІ» (`tablo.bus-ua.info/zhytomyr`); міжміські тарифи
  в Україні не регулюються й офіційно ніде не публікуються;
- реєстри Укртрансбезпеки на data.gov.ua (CC BY) — розклади по зупинках без цін, оновлювались у 2018–2021;
- автостанція Малин не підключена до жодної мережі продажу: цін Малин → Житомир онлайн **не існує** (каса
  (073) 182-40-49, (068) 777-15-90); у базі ці ціни порожні — і лишаються порожніми;
- автобуса Малин ↔ Коростень не існує;
- тариф «Зубастика» (Київ ↔ Малин) оголошують у новинах malyn.media / ІнфоМалин — тому стрічка новин теж джерело.

**Нагляд лише сигналізує.** Нічого не перезаписує в `Schedule`: ціну в базі міняє власник, подивившись на табло.

## Рішення

1. **Розширюємо наявний нагляд**, не пишемо новий: `backend/src/transport-source-watch.ts` (`WATCHED_SOURCES`, `WatchedSource`
   у базі, таймер, панель `SourceWatchPanel` на `/admin/route-schedule`). Міграції нема: нове джерело = рядок у списку.
   Правила ті самі: перший запуск — baseline без сповіщення, одне сповіщення на зміну (умовний `updateMany` за старим
   відбитком), сторінка без таблиць / стрічка без записів — збій, а не зміна.
2. **Табло Житомир-1** — новий `kind: 'bus-board'`, парсер `zhytomyr-board-parser.ts` (чистий, тестований на фікстурі).
   Беруться рядки, де МАЛИН — кінцева (Житомир → Малин і транзити Станишівка / Хмільник / Вінниця → Малин) або старт
   (Малин → Хмільник / Вінниця). Табло показує сьогодні й завтра — рейс рахується один раз (ключ: час + звідки + куди).
   **Відбиток** = набір (час, маршрут, ціна, перевізник); кількість місць, статус продажу й модель автобуса міняються
   щодня й у відбиток не входять. Назва перевізника нормалізується (на табло «РIМ-Богдан» з латинськими I/M поруч із
   «РІМ-БОГДАН»): латиниця → кирилиця, великі літери. Частина = напрямок («Житомир → Малин»), рядок частини =
   «08:25 · 339,30 грн · ПП «РІМ-БОГДАН»». Сповіщення перелічує саме рейси: «08:25 Житомир → Малин: 299,00 → 339,30 грн
   (ПП «РІМ-БОГДАН»)», «новий рейс 07:00 Житомир → Малин: 334,80 грн (…)», «зник рейс 11:15 Житомир → Малин».
3. **Звірка з базою.** Рейси з кінцевою Малин порівнюються з `Schedule` маршруту `Zhytomyr-Malyn` за `departureTime` (час на
   табло = відправлення з Житомира, як і в базі; для транзитів теж). Ціна «збігається», коли округлена ціна табло =
   `priceUah` (334,80 → 335). Рядки «Малин → …» з базою не звіряються: на табло стоїть час проходження через Житомир, а в
   базі — відправлення з Малина. Сповіщення про зміну табло додає блок «База:» з розходженнями; панель адмінки показує
   таблицю останнього знімка з колонкою «У базі». Нічого не пише.
4. **Окремий інтервал для табло** — `TRANSPORT_BOARD_WATCH_INTERVAL_MIN` (за замовч. **720**, 0 = вимкнено), тобто двічі на
   добу; джерела з `group: 'board'` ходять лише цим таймером, решта — як і раніше `TRANSPORT_SOURCE_WATCH_INTERVAL_MIN`
   (360). Запобіжник: табло не запитується частіше ніж раз на годину навіть кнопкою «Перевірити зараз» (статус `skipped`).
   Лише HTTP (TLS у них нема). `robots.txt` табло дозволяє `/zhytomyr`; `bus.com.ua/cgi-bin/tablo.pl` робот не чіпає
   (там `Disallow: /cgi*`) — це запасний адрес для людини. User-Agent усіх запитів нагляду називає сайт і контакт:
   `malin.kiev.ua transport-source-watch/1.1 (+https://malin.kiev.ua/about)`.
5. **CKAN data.gov.ua** — наявний `ckanSource` отримує параметр міста; п'ять наборів (два Укртрансбезпеки, три Малинської
   міськради) з `cityCode: 'Malyn'`. Сигнал — зміна дати / адреси / розміру файлів набору (як і для Коростеня).
6. **malyn.media.** Стаття «Автостанція Малин» — `kind: 'html-tables'` з парсером `station-table`: частина = таблиця,
   рядки = «06:30 Малин — Житомир через Радомишль», тож сповіщення називає змінені відправлення. Стрічка `/feed/` —
   новий `kind: 'rss'` з фільтром за словами (`подорожча`, `маршрутк`, `тариф`, `зубастик`) у заголовку й описі; частина =
   запис (ключ — посилання), **раніше бачені записи зберігаються** в деталях рядка, тож запис, що випав із 20 останніх,
   не дає «зникло»; новий збіг → сповіщення із заголовком і посиланням. Пошукову стрічку `?s=` не використовуємо —
   `robots.txt` сайту її забороняє.
7. **Фікстури без мережі** — `backend/src/__fixtures__/`: живі сторінки від 17.11.2026, обрізані до потрібної розмітки
   (шапка, заголовки таблиці, усі рядки з МАЛИН і кілька чужих; стаття — meta + абзаци перед таблицею + таблиця; стрічка —
   канал і три записи зі скороченим текстом). Байти рядків — як на сайті.
8. **Атрибуція** табло в панелі адмінки й у `Docs/transport-open-data.md`: «за даними табло автовокзалу Житомир-1
   (МПП «ВПІ»)». Власнику — написати `webmaster@bus.com.ua` / `support@bilet-ua.com` про посилання на їхнє табло
   (їхній link-to-me), див. «Питання власнику».
