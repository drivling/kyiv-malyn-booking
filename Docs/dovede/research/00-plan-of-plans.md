# «Доведе» — большой план планов

> «Язик до Києва доведе». **Спитайте своїми словами — і доведе.**

## Контекст

Владелец хочет новую секретную страницу (пока видит только админ, как превью схемы Коростеня): одна строка поиска
посередине, как у Google. Человек пишет обычной речью («Як доїхати з Києва (Святошин) до Малина на вокзал»,
«з Царського села до Києва завтра зранку»), а сайт отвечает короткой **историей**: фраза, карточка междугородней
поездки (маршрутка или электричка, кнопка «Забронювати»/«Квиток»/«Подзвонити»), короткая записка о пересадке,
карточка городского автобуса Малина (номер, время, остановка → остановка; тап открывает `/transport`) и в конце
«пройдіть 300 м пішки». Если не сказано, чем ехать, и вариантов несколько, появляются нумерованные карточки
«1 · Маршрутка 07:40→09:30 · 2 · Електричка 08:15→10:25».

Зачем: у сайта уже есть проверенные данные (маршрутки и электрички Киев/Житомир/Коростень ↔ Малин, попутки,
городской транспорт Малина с планировщиком пересадок RAPTOR) и есть Claude API (Джура). «Доведе» соединяет их в
персонального помощника по транспорту: всё, что умеет сайт, но спросить простыми словами.

**Принятые решения:** название «Доведе», адрес `/dovede`; модель `claude-opus-5-5`, как у Джуры, переключается
переменной `DOVEDE_MODEL`; сразу после утверждения делаю **только Фазу 0** (документ, эталонные вопросы,
кликабельный прототип), потом пауза, чтобы вы посмотрели.

## Главный принцип: «ИИ понимает — наши данные отвечают»

```
текст ─► [1] понимание в браузере (словарь мест, мгновенно, без сети) ──┐
     └─► [2] Claude: текст → TripIntent JSON (только id из словаря) ────┤ слияние
                                                                         ▼
     [3] сборщик историй в браузере: /poputky/search (маршрутки, электрички)
         + «якоря» (где междугородний транспорт касается остановок Малина)
         + планировщик RAPTOR (/transport) ─► истории ─► [4] текст по шаблонам
```

1. **Claude никогда не пишет время, номер или цену.** Он только превращает текст в структуру: откуда, куда, когда,
   чем. Всё остальное берётся из наших данных, текст собирается по украинским шаблонам. Так он не может ничего
   выдумать.
2. **Сначала местный разбор.** Если словарь в браузере однозначно понял всю фразу, ответ строится сразу. Claude
   вызывается параллельно; пока страницу видит только админ, это нужно для журнала и сравнения. Если Claude понял
   иначе, внизу тихая подсказка «Можливо, ви мали на увазі…». Если Claude недоступен, страница работает на местном
   разборе.
3. **Маршрут строится в браузере.** Сервер нужен только для понимания текста. Планировщик и данные — те же, что уже
   работают на `/transport` и `/mizhgorodski`, поэтому ответы «Доведе» никогда не расходятся с остальным сайтом.
4. **Секретность защищает сервер, а не интерфейс.** `POST /admin/dovede/understand` закрыт `requireAdmin`.
   Страница не делает ничего, пока токен админа не подтвердился через `/admin/check`; неадмин видит пустоту, как на
   любом несуществующем адресе. Код страницы загружается отдельным файлом (первый `React.lazy` в проекте) и не
   попадает в предзагрузку service worker. Адрес не появляется ни в меню, ни в sitemap, ни в robots.txt, ни в
   llms.txt.

### Контракт понимания (черновик, финал в Фазе 0)

```ts
TripIntent {
  from: PlaceRef | null;  to: PlaceRef | null;  via?: PlaceRef
  when: { day: 'today' | 'tomorrow' | 'YYYY-MM-DD'; time?: 'HH:MM';
          kind: 'depart' | 'arrive' | 'any'; part?: 'morning' | 'day' | 'evening' }
  modes: ('marshrutka' | 'elektrichka' | 'poputka' | 'city_bus')[]   // пусто = любой
  intent: 'trip' | 'schedule' | 'price' | 'contact' | 'other'
  unknown: string[]          // слова про места, которых нет в словаре
  confidence: 'high' | 'medium' | 'low'
}
PlaceRef = { id: string /* id из словаря */, text: string /* как написал человек */ }
```

**Словарь мест (gazetteer):**
- города: `city.Kyiv`, `city.Malyn` и т.д., коды как в `TripPoint`;
- точки посадки в Киеве: `kyiv.akadem`, `kyiv.sviatoshyn`, `kyiv.pas`, `kyiv.borshch`;
- места Малина: `malyn.vokzal` → st_0019, `malyn.avtostantsiya` → st_0004/0005, `malyn.tsentr`, `malyn.tsarske` →
  st_0090 (основа — `SCHEME_NODES`);
- ориентиры `lm.*`;
- сырые остановки `st_XXXX`;
- у каждого места синонимы: украинские, русские, транслит, падежи.

Курируемый файл синонимов — одинаковая копия на фронтенде и бэкенде с тестом сверки, как `trip-timing.ts`.
Остановки подмешиваются из датасета. Системный промпт байт-стабилен, поэтому кэшируется.

**Якоря** (`frontend/src/pages/DovedePage/data/anchors.ts`) — где междугородний рейс касается остановок Малина и со
сдвигом в сколько минут:
- маршрутка из Киева: «Бандери» прибытие−10, «Центр» прибытие−5, «Автостанція» в момент прибытия;
- электричка: вокзал st_0019 в момент прибытия;
- в обратную сторону: посадка на автостанции или в центре, сдвиг от отправления.

Флаг `confirmed: false` превращает слово в истории в «зазвичай». Если у маршрутки нет `arrivalTime`, время прибытия
считается приблизительно («≈ 10:40») и в историю добавляется запасной автобус. Тесты проверяют, что каждая остановка
и каждое место посадки существуют в данных.

## План планов: фазы

Каждая фаза — отдельный PR от `origin/main`, со своим подробным планом перед стартом. Прогресс и решения ведутся в
файле восстановления `Docs/dovede-roadmap.md`.

### Фаза 0 — Фундамент: документ, эталонные вопросы, прототип *(делаю сразу после утверждения)*
- Ветка `dovede/phase-0` от `origin/main` в отдельном worktree: `help` отстаёт на 20 коммитов и в нём есть
  незакоммиченные файлы, его не трогаю. В worktree делаю `npm ci`, иначе husky pre-commit не пройдёт.
- **`Docs/dovede-roadmap.md`** (по-украински, в стиле `dzhura-roadmap.md`). Это файл восстановления: статус,
  принципы, контракты (`TripIntent`, id словаря, якоря), фазы, риски, раздел «Що знає лише власник» с галочками.
- **`frontend/src/pages/DovedePage/eval/golden.json`** — 45+ эталонных вопросов, у каждого
  `{id, text, now, expect, tags, scope}`:
  - Киев→Малин ×10, Малин→Киев ×10;
  - формулировки времени ×8;
  - явный вид транспорта ×5;
  - русский язык, суржик, транслит, опечатки ×6;
  - неполные вопросы ×4;
  - вне зоны ×4;
  - не про поездку ×3.
- **Кликабельный прототип** `Docs/dovede/prototype.html`: один файл, фейковые данные, светлая и тёмная тема, ширина
  телефона. Плюс приватная ссылка-Artifact, чтобы открыть с телефона. Состояния:
  1. пустое: строка, примеры-чипы, плитки мест;
  2. набор текста: подсветка распознанных слов и строка «з [Київ, Святошин] до [Малин, вокзал] · [сьогодні] ·
     [будь-яким]» со слотами, которые можно поправить;
  3. ожидание: статус собирается из понятых слов;
  4. уточнение: карточки 1/2/3 с готовым ответом, клавиши 1/2/3;
  5. история Киев(Святошин)→Малин вокзал: рельс с цветами этапов, карточки маршрутки и автобуса, пешком;
  6. обратная история Царське село→Киев;
  7. ошибки: незнакомое место, рейсов сегодня уже нет, городские автобусы уже не ходят.
- Коммит в ветку (сообщение на английском). Пуш и PR — по вашему слову.
- **Готово, когда:** вы прокликали прототип и ответили на вопросы «что знаете только вы».

### Фаза 1 — Работающая страница без ИИ (только фронтенд, видит только админ)
- **Каркас:**
  - `App.tsx`: ленивый маршрут `/dovede` за тихой проверкой `AdminOnly` (не `ProtectedRoute`: тот показал бы
    форму входа и выдал страницу);
  - `/dovede` в `PRIMARY_ONLY_PATHS` (`frontend/scripts/site-hosts.mjs`) и исключение в `gaShouldTrackPath`
    (`frontend/src/analytics/googleAnalytics.ts`);
  - файл страницы исключён из `frontend/scripts/precache.mjs`, с тестом;
  - `usePageSeo({ robots: 'noindex, nofollow' })`.
- **Планировщик:** новый хук `LocalTransportPage/journey/usePlannerModel.ts(city)`. Порядок как на странице остановки:
  датасет → `configureSegmentDurations` → `buildTimetable` по дню. Всегда `DEFAULT_TRANSPORT_CITY` (Малин), а
  2000-строчный `LocalTransportPage.tsx` в этой фазе не трогаю.
- **Понимание:** `DovedePage/nlu/`:
  - нормализация: апострофы, і/и/ї, ё/е;
  - предлоги з/від/с/от → откуда, до/в/на/к → куда, через;
  - префиксы основ и опечатки ≤1;
  - время и день: зранку, о 8, щоб бути до 9, завтра;
  - виды транспорта; «автобус» и «до» помечаются как неоднозначные.
- **Сборщик:** `DovedePage/compose/`:
  - `intercity.ts`: рейсы из `/poputky/search`, дубли электричек по `tripNumber` схлопываются, прибытие
    определяется по `arrivalTime` → `durationMinutes` → типичное время из якоря;
  - `composeStories.ts`: по каждому якорю `planDay` и `journeyWindow`, лучшее итоговое прибытие, сравнение с
    «пешком», в обратную сторону `arrive`-by;
  - `narrate.ts`: шаблоны текста.
- **Карточки:** `DovedePage/ui/` — `IntercityCard`, `CityBusCard` (ссылка
  `/transport/route/:id?d=&h=&stop=&to=&dir=`), `WalkNote`, `ChoiceCards`.
- **Переиспользуется:** `BusBookingModal`, `TrainTicketModal`, `isPhoneOnlySchedule` (маршрутки Киев–Малин сейчас
  только по телефону, поэтому кнопка «Подзвонити»), `routeNo()`, `textColorOn()`.
- **Тесты:**
  - `parseLocal` даёт ≥ 80% точности слотов на эталонах MVP;
  - целостность словаря и якорей;
  - `composeStories`: прибытие неизвестно, прибытие после последнего автобуса, обратная сторона, оба вида
    транспорта;
  - неадмин получает пустоту и не загружает файл страницы.
- **Готово, когда:** 10 сценариев сходятся с `/transport` при ручной проверке, главный бандл вырос не больше
  ~1 КБ, все существующие тесты зелёные.
- **Не входит:** Claude, журнал, подсказки при наборе.

### Фаза 2 — Мозг: Claude понимает текст
- **Бэкенд:**
  - `@anthropic-ai/sdk` (CommonJS, Node 20), `package-lock.json`, пересобранный `dist/`;
  - `backend/src/dovede/`: `places-curated.ts`, `intent.ts` (схема и `validateIntent`), `gazetteer.ts`,
    `prompt.ts`, `understand.ts`, `guard.ts`;
  - `routes/admin-dovede.ts`, подключается в `create-app.ts`.
- **Вызов Claude:**
  - `client.beta.messages.create`, модель из `DOVEDE_MODEL` (по умолчанию `claude-opus-5-5`);
  - `output_config: { effort: 'low', format: { type: 'json_schema', schema } }`;
  - `betas: ['server-side-fallback-2026-07-01'], fallbacks: 'default'` (так же, как у Джуры);
  - `max_tokens` ~4000, таймаут ~8 с, одна повторная попытка;
  - `refusal` или `max_tokens` → местный разбор;
  - системный промпт кэшируется; «сьогодні/зараз (Київ)» передаётся только в сообщении пользователя;
  - id, которых нет в словаре, сервер переносит в `unknown`.
- **Журнал:** таблица `DovedeQuery` (миграция Prisma): текст ≤ 300 символов, местный и ИИ-разбор, модель, задержка,
  токены, в том числе прочитанные из кэша, ошибка.
- **Переключатели:** `DOVEDE_ENABLED`, `DOVEDE_DAILY_CAP`; ключ — уже существующий `ANTHROPIC_API_KEY`. Обновить
  `.env.example` и `CLAUDE.md`.
- **Тесты (supertest):**
  - 401 без токена;
  - 429 при исчерпанном дневном лимите и 503 при выключенном переключателе, оба ответа с `{fallback:'local'}`;
  - id не из словаря переносится в `unknown`;
  - промпт байт-в-байт одинаковый между вызовами;
  - копии файлов на фронтенде и бэкенде совпадают.
- **Ручной прогон эталонов** с `DOVEDE_EVAL=1`, не в CI, как `TRANSITOUS_ORACLE`.
- **Готово, когда:**
  - ≥ 90% точности слотов на эталонах;
  - половина ответов быстрее 3 с;
  - со второго вызова `cache_read_input_tokens > 0`;
  - без ключа страница работает.

   подбирает в обратную сторону. Сейчас в данных только «можна сісти й у центрі».

4. Подсказки по Киеву: «Святошин → Академмістечко, 2 станції метро». Давать ли ссылку на Google Maps.
5. Что отвечать на вопросы вне зоны (Львов) и про попутки до Фазы 6.
6. Куда поставить себе вход на `/dovede`: ссылка в админке или только закладка.

## Риски и как их закрываем
| Риск | Ответ |
|------|-------|
| У маршруток нет времени прибытия | «≈», запасной автобус, позже `arrivalTime` в админке |
| Нет данных о транспорте Киева | Только текстовые подсказки к точке посадки |
| После полуночи планировщик не считает | Падаем в «пішки» или «автобуси вже не ходять» |
| ИИ выдумает место или время | Только id из словаря, проверка на сервере, цифры только из данных |
| Секретность | Защищает `requireAdmin`; файл страницы не в бандле и не в precache; адрес нигде не публикуется. Сам путь виден в коде главного бандла, это приемлемо |
| Стоимость | Только админ, дневной лимит, выключатель, кэш промпта (~1–2 цента за вопрос) |
| Разошлись ветки | Каждая фаза — новая ветка от свежего `origin/main` (вы быстро сквошите) |
