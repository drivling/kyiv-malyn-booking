## Як

1. Експорт журналу (≤ 366 днів за раз):
   `GET /admin/dzhura/chats/3167014/export?from=2025-11-24&to=2026-11-24` і `…from=2024-11-24&to=2025-11-23`.
2. Аватарки: `POST /admin/dzhura/jobs {type:'avatars', chatId:3167014}` → `GET /admin/dzhura/jobs/:id` →
   `result` у файл `avatars.json` (`{ avatars: { tgUserId: base64 } }`).
3. Рендер (локально, `frontend/`):
   `node scripts/dzhura-history/render.mjs --export prev.json --export osbb.json --avatars avatars.json --mode chunk --out out/chunk`
   (`--mode single` — картинка на повідомлення, `text` — HTML-пости; `--from/--to` — діапазон tgMessageId).
4. Публікація: `DZHURA_ADMIN_TOKEN=… node scripts/dzhura-history/post.mjs --chat <id> --batch <name> [--say "…"] --dir out/chunk`.
   Тихо, пауза 3 с, FloodWait чекає, збій зупиняє решту партії; повтор із тим самим `--batch` пропускає опубліковане.

Скільки постів на всю історію: single — 1894, chunk — 666 картинок (≈ 76 МБ), text — 104, posts (пост на
повідомлення: шапка з аватаркою + текст підписом) — ≈ 1900.

Вбудований імпорт: `render.mjs --mode import [--format android|ios|android-slash] [--attach-avatars]` пише `chat.txt`
у форматі експорту WhatsApp (відповіді — рядком «↪ Ім'я: «…»», переслане й медіа — позначкою), далі
`import.mjs --chat <id> --dir <out> --dry-run` (перевірка формату й прав), потім без `--dry-run`.

Що показав тест імпорту (2026-11-23):
- Імпорт приймають лише **супергрупи**: у звичайну групу `initHistoryImport` відповідає `PEER_ID_INVALID`, хоча
  `checkHistoryImportPeer` проходить (тестову групу власник перевів у супергрупу: тепер `DzhuraChat.id` 3923088,
  `tgChatId` -1004412281027; стара 3167013 лишилася в базі). ОСББ — супергрупа.
- Повідомлення стають у **день імпорту** (не в минуле), кожне з оригінальною датою й ім'ям автора; відправник —
  службовий «Imported Message», ім'я — у `fwd_from.from_name`. Картинки (`IMG-….jpg (file attached)`) прикріпилися.
- Час у файлі Telegram читає як **UTC+3** незалежно від сезону, тож генератор пише час у UTC+3
  (`WA_IMPORT_OFFSET_MIN`), а не київський — інакше зимові повідомлення показувалися на годину раніше.
- Між імпортами в одну групу Telegram вимагає паузу 5 хв (`PREVIOUS_CHAT_IMPORT_ACTIVE_WAIT_5MIN`).
- «Змішаний» варіант (прохання власника): імпорт, де до кожного повідомлення прикладено шапку як у `--mode posts`
  (аватарка, ім'я, дата) — `render.mjs --mode import --attach-headers`; шапка ≈ 7–11 КБ.
- Для повного прогону змішаного імпорту (≈ 1900 картинок) однієї задачі замало (≤ 20 картинок, тіло ≤ 2 МБ):
  потрібен імпорт у кілька задач (init → media частинами → start) і рішення про ≈ 17 повідомлень довших за підпис
  до фото (1024 символи).
