# «Доведе» · куди люди їдуть у Києві — стартовий список для `npm run dovede:crawl -- --places scripts/data/dovede-places-kyiv.txt`.
# По одному місцю в рядку, так, як його написала б людина після «до Києва до …». Ключ у базі — слова як написані:
# «Охматдит» і «лікарня Охматдит» — різні записи, тому одне місце — один раз, найкоротшою звичною назвою.
# Станції метро, вокзал і міську електричку сюди не пишемо: їх «Доведе» знає сам (скрипт такі рядки пропускає).
# Назву без слова «Київський» на початку: після «до Києва» сторінка читає його як назву міста.
# Без прийменників усередині («Епіцентр на Кільцевій» сторінка обрізає до «Епіцентр») і без слова «імені»
# (словник сторінки поки псує його на «іменя»): «Університет Драгоманова», а не «Університет імені Драгоманова».
# Кожне нове місце — один запит до Google на кожну точку висадки й кожен час із --when.
