# UX розділу /transport — що відтворено з Jakdojade і що змінено

Оновлено: 2026-10 (PR #51 «вузли, токени, карта, планер» і PR «сторінка маршруту і табло»).
Розділ «UX 2026-10» нижче — поточний стан; розділ «Jakdojade-ера (2026-08/09)» лишено як історію
рішень, які ці зміни свідомо переглянули.

## Кольори (сайт, не wtk-red)

Плановий `wtk-red #E30613` **свідомо не повернуто**: публічний сайт на BBC cyan (`#00aff5` / текст
`#054752`), і транспорт має виглядати як частина того самого продукту. Усі кольори розділу — токени
`--lt-*` у блоці `.lt-page` (`LocalTransportPage.css`), шрифт — Golos Text лише для `/transport*`.
Лінії мають кольори зі схеми (`scheme/malyn-scheme-routes.ts` → `routeColorStyle`): бейджі, лінії на
карті, таймлайн, чіпи ліній на табло. Origin/destination: зелений `#0fa573` / cyan `#00aff5`.

## UX 2026-10 — поточний стан і чому так

Принцип: той самий рівень і мова, що й у схеми маршрутів (`/transport/scheme`) — лінії як головні
обʼєкти, вузли замість хмари крапок, жодного порожнього екрана, один жест = одна дія, одна мова
форм (чіпи-пігулки, 12 px картки, бейджі 6 px, токени).

### Планувальник (`/transport`, `/transport/:from/:to?d&h`)
- Картка пошуку: два поля одне над одним, лейбл — лише маркер (кільце origin/destination, як на
  карті) з пунктиром між ними; текст «Звідки»/«Куди» — для скрінрідера, у плейсхолдерах «Звідки
  їдемо?»/«Куди їдемо?». Так довгі назви зупинок читаються повністю в будь-якому шрифті (e2e міряє).
- Геолокація — іконка-приціл усередині порожнього поля «Звідки» (слот `trailing` Combobox);
  результати — список найближчих з кнопкою «Табло».
- Дата/час — рядок чіпів «Зараз» / «Завтра» / «Сьогодні о 09:12» (останній розгортає нативні
  поля); на телефоні поруч чіп «Карта».
- Кнопки «Знайти» немає: видача жива, URL синхронізується сам (replace), нова пара мʼяко прокручує до
  результатів (не при відкритті з адресного рядка).
- Швидкий старт замість порожнього екрана: «Куди їдете?» з чіпами вузлів схеми (перший тап — «Куди»,
  наступний — «Звідки»), «Поруч зі мною», уся схема мініатюрою.
- Результати — табло найближчих відправлень: картки за часом очікування (не за номером), бейдж лінії,
  «→ кінцева», великий час, «через N хв» (лише сьогодні) / «рейсів пізніше немає · перший наступного
  дня», рядок «далі 09:40 · 10:55» (`findUpcomingTrips`). Каталог ліній — картки з «через …» зі схеми.
- Карта: тайли OpenStreetMap, приглушені CSS-фільтром (CARTO Positron вимагає API-ключ; провайдер —
  через `VITE_MAP_TILES_URL`), лінії всіх перевірених маршрутів у кольорах схеми, вузли схеми підписані,
  решта зупинок — дрібні кола. Тап по зупинці → одна картка «Звідси / Сюди / Табло» (попап і
  радіальний пікер прибрано). На десктопі — колонка праворуч зі смужкою «З … ⇅ До …»; на телефоні —
  повноекранний overlay за чіпом «Карта» (`LocalTransportMapOverlay`, «Готово»/Escape) замість
  нижнього аркуша. Карта не «стрибає» на фіт при кожному рендері.

### Сторінка маршруту (`/transport/route/:id?stop&to&dir&time&d&h`)
- URL — єдине джерело пари, напрямку й обраного рейсу: `stop`/`to` резолвляться в зупинки маршруту,
  `dir` з URL → випливає з пари → belongs_to «Звідки» → «туди»; `time` — час на «Звідки» (або на
  першій зупинці); без `time` — найближчий до `h` (сьогодні — не раніше за зараз) рейс.
- Вибір пари — тапами по таймлайну зупинок: перший «Звідки», другий «Куди», наступний — нова пара;
  «Скинути» у шапці секції. Комбобокси «Оберіть зупинки» + «Показати розклад» прибрано (разом із
  багом, коли після «Показати розклад» стан не оновлювався).
- Таймлайн у кольорі маршруту: білі вузли з кільцем, «Звідки»/«Куди» — кільця origin/destination,
  відрізок між ними товщий; «Табло» — маленьке посилання в кожному рядку; «до наступної» — у хвилинах.
- Розклад: чіпи дати/часу, стрічка відправлень (чіпи з часом на «Звідки» і прибуттям на «Куди»,
  найближчий натиснутий, тап закріплює `time`), «Повний розклад» — чіп-перемикач (розгорнуто на
  десктопі, згорнуто на телефоні, у друці завжди).
- Шапка: іконка «Назад», бейдж + назва лінії, чіп «проїзд 20 ₴», сегментований перемикач
  «Туди / Назад» (бере найближчий рейс, не перший), на телефоні чіп «Карта».

### Табло (`/transport/stop`, `/transport/stop/:id?d&h&line`)
- Зупинка — з URL (джерело істини), як і раніше; під назвою — чіпи ліній, що відправляються зі
  зупинки (порядок і кольори схеми); тап фільтрує картки і пише `?line=`.
- Картка пошуку — один рядок чіпів: дата/час, «Весь день», «Поруч зі мною».
- Порядок секцій: відправлення → міні-схема «ви тут» → стаття «Про зупинку» → FAQ.
- Картки відправлень — у мові карток планувальника (час, «через N хв», бейдж, «→ кінцева»),
  найближча — зі смугою origin.

### Незмінні контракти
URL-схема всіх сторінок, gtag-події (`transport_search`, `_swap`, `_date_chip`, `_route_card_click`,
`_no_route`, `_nearby_pick`, `_geo`), `routeColorStyle`, пререндер і sitemap, 16 px інпути на
мобільному (iOS-зум), 44 px цілі дотику.

## Jakdojade-ера (2026-08/09) — історія

Нижче — рішення того циклу; те, що переглянуто у 2026-10, позначено «→».

### Головна (`/transport`, `/transport/З/До`)
- Поля «З» над «До» (лейбл-крапка в рядку з полем, ⇅ праворуч) → лейбли-маркери, текст схований.
- Дата/час згорнуті в «Сьогодні, 09:12 · Змінити» → рядок чіпів.
- Результати живі (replace); «Знайти» — push + скрол → кнопки немає, прокрутка при появі пари.
- Поки в полі недодрукований текст — попередні результати і підказка «Оберіть зупинку зі списку»;
  «×» скидає лише своє поле (інше лишається в URL). Без змін.
- «Немає прямого маршруту» пропонує сусідні зупинки (до 400 м). Без змін.
- Картка: відправлення з «З», «через N хв» (лише сьогодні), `№ → кінцева`, `09:24 → 09:41 · 17 хв`
  → плюс сортування за часом і «далі …».
- Desktop: ліва панель + карта; mobile: bottom sheet (collapsed / mid / full) → overlay.
- Geo «Поруч зі мною» (заповнює «З», фокус на «До») → іконка в полі; SubNav → табло тієї ж зупинки.

### Деталь (`/transport/route/:id?...`)
- Бар назад + № лінії + З→До + дата/час → шапка з чіпами.
- Перемикач напрямку з rematch зупинок за координатами → лишився, бере найближчий рейс.
- Tablica Відправлення | Прибуття (+ select як mobile fallback) → стрічка відправлень + «Повний розклад».
- Таймлайн зупинок із сегментів dataset; badges З/До → таймлайн з тапами, бейджі «Звідки»/«Куди».

### Табло (`/transport/stop`, `/transport/stop/:id`)
- Зупинка з URL, підказка «Оберіть зупинку зі списку», «×» → `/transport/stop`. Без змін.
- Та сама форма, що в планувальника; дата/час застосовуються одразу. Без змін (чіпи замість «Змінити»).
- Countdown-картки, «весь день», deep-link у detail з `stop,dir,time,d,h`; «Назад» з маршруту
  повертає на табло → картки в мові планувальника, «Весь день» — чіп, чіпи ліній `?line=`.
- Desktop: карта з усіма зупинками; mobile: карти немає. Без змін.
