# Промпт для ChatGPT (вручну з фото меню)

Скопіюй текст нижче в ChatGPT, **прикріпи фото меню** столової, надішли.
У відповіді має бути **тільки JSON** — його потім згодовуєш скрипту `import_menu`.

---

## Текст промпта (копіюй як є)

```
Ти розпізнаєш меню їдальні з фото (українською або російською).

Поверни ТІЛЬКИ валідний JSON, без пояснень і без markdown-огорожі ```.

Формат строго такий:
{"items":[{"name":"Назва страви","price":123}]}

Правила:
- name — коротка назва страви як на меню, БЕЗ ціни в рядку
- price — ціна в гривнях, ціле число (не рядок)
- пропусти заголовки: «Меню», дату, «перше/друге/гарнір», декоративний текст
- якщо ціни на фото немає або не читається — цю позицію ПРОПУСТИ
- не вигадуй страви й ціни, яких немає на фото
- якщо одна страва з кількома варіантами цін — окремі items
- мову назв збережи як на фото (укр/рос)

Приклад відповіді:
{"items":[{"name":"Борщ","price":55},{"name":"Котлети курячі","price":75},{"name":"Пюре","price":40}]}
```

---

## Що робити з відповіддю

1. Скопіюй JSON з відповіді ChatGPT (якщо обгорнув у \`\`\`json — можна цілком, скрипт зніме огорожу).
2. Збережи в файл, наприклад `menu.json`, або встав у stdin.
3. Запусти імпорт (БД + повідомлення в групу від твого акаунта):

```bash
cd backend/telegram-user
export DATABASE_URL="postgresql://..."
export TELEGRAM_API_ID="35076972"
export TELEGRAM_API_HASH="..."
export TELEGRAM_USER_SESSION_PATH="$(pwd)/session_telegram_user"

# з файлу:
python3 -m lunch.import_menu menu.json

# або з буфера:
pbpaste | python3 -m lunch.import_menu
```

У групі з’явиться читабельне меню, у Postgres — `LunchDay` + `LunchMenuItem` на сьогодні.
